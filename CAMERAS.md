Two side panels rotate every 60 and 75 seconds. Active countries cannot repeat across panels. Player failures skip to another camera; unavailable streams are temporarily excluded. A catalogue check runs during each live website build using the existing YouTube Data API key. Only metadata are fetched. A failed metadata request is reported as unverified, never as live.

Live city views provide visual context only. They are not part of the research dataset or evidence of military activity.

The source feed cycles retained observations, pauses on hover/focus, and keeps the collection week visible. Motion can be paused. Reduced-motion preferences disable automatic source cycling and camera rotation by default.
